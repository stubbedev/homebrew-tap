# stubbedev/homebrew-tap

Homebrew tap for tools by [stubbedev](https://github.com/stubbedev).

Each formula installs the prebuilt release binary for your platform and is
updated automatically whenever the corresponding project publishes a release.

## Install

| Formula | Install | Source |
| ------- | ------- | ------ |
| harness | `brew install stubbedev/tap/harness` | [stubbedev/harness](https://github.com/stubbedev/harness) |
| proxy-mcp | `brew install stubbedev/tap/proxy-mcp` | [stubbedev/proxy-mcp](https://github.com/stubbedev/proxy-mcp) |
| ds-mcp | `brew install stubbedev/tap/ds-mcp` | [stubbedev/ds-mcp](https://github.com/stubbedev/ds-mcp) |
| parts-finder | `brew install stubbedev/tap/parts-finder` | [stubbedev/parts-finder-mcp](https://github.com/stubbedev/parts-finder-mcp) |
| treeman | `brew install stubbedev/tap/treeman` | [stubbedev/treeman](https://github.com/stubbedev/treeman) |
| laravel-dev-mcp | `brew install stubbedev/tap/laravel-dev-mcp` | [stubbedev/laravel-dev-mcp](https://github.com/stubbedev/laravel-dev-mcp) |
| pty-mcp | `brew install stubbedev/tap/pty-mcp` | [stubbedev/pty-mcp](https://github.com/stubbedev/pty-mcp) |
| srv | `brew install stubbedev/tap/srv` | [stubbedev/srv](https://github.com/stubbedev/srv) |
